# Internationalization (nb + en) — planned, not built

**Goal:** serve the site in Norwegian (default) and English. English is mainly a **tourist aid** — visitors are routinely surprised by Norway's strict alcohol-sales rules, so the "hvorfor er reglene så strenge" and age-limit content are the highest-value to translate first.

**Status (2026-06-20):** not started. Everything is hardcoded Norwegian (`nb`). This file is a checklist for whoever picks it up.

## What to touch

- **`<html lang>`** in `resources/views/layouts/app.blade.php` — currently hardcoded `nb`; make it per-locale.
- **`og:locale`** — currently `nb_NO`; add `og:locale:alternate` (`en_GB`/`en_US`) for the other locale.
- **`hreflang`** alternate `<link>` tags for `nb`, `en`, and `x-default`.
- **URL strategy** — decide: subpath (`/en/...`, simplest for SEO + sitemap), subdomain, or Accept-Language redirect. Lean subpath.
- **Hardcoded strings to translate:**
  - `app/Pages/HomeBuilder.php` — FAQ Q&As, today/avvik labels, description.
  - `app/Pages/DatePageBuilder.php`, `HubBuilder.php`, `MonthBuilder.php` — ledes, headings, FAQ copy.
  - Blade views + components (`hero`, `hours-table`, `deadline-table`, `week-table`, `faq`, partials `caveat` / `store-closing-note`), table headers ("Dag", "Øl i butikk", "Vinmonopolet"), section titles.
  - Hero rotating strings in `resources/js/app.js`.
- **Date / holiday names** — Carbon locale is `nb`; switch per-locale. Yasumi has `en_US`, but the Norwegian legal day names likely need hand-written EN copy.
- **Slugs / routes** — month names, date slugs (`16-mai`), season slugs (`paske`) are Norwegian. Decide whether EN gets translated slugs or reuses the NO slugs under `/en/`.
- **`sitemap.xml`** — emit locale alternates.
- **`<title>` / meta description** — per locale.

## Notes

- Keep the calendar/resolver (`app/Calendar`) language-agnostic — it already returns dates/bands, not display text. Only the *presentation* layer needs translating.
- A language switcher in the header (`layouts/app.blade.php`) will be needed.
